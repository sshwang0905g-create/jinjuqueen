Vercel 서버리스 Git DB 시스템

외부 DB 비용 없이 GitHub 저장소를 DB로 영구 활용

동작 방식 (Git as a Database)

관리자 모드에서 매물 상태를 변경하거나 AI 칼럼을 작성하면, Vercel 서버리스 API가 GitHub 저장소의 data/board.json과 data/properties.json 파일에 직접 자동 커밋(Commit)하여 영구 보존합니다.

Vercel 배포 시 필요한 환경변수 (30초 설정)

GITHUB_TOKEN = ghp_xxxxxxxxxxxx (GitHub 토큰)
GITHUB_OWNER = 본인 GitHub 아이디
GITHUB_REPO = jinjuqueen (저장소 이름)
GITHUB_BRANCH = main (기본 브랜치)
ADMIN_PASSWORD = 대표님 설정 비밀번호

💡 환경변수가 등록되면 Vercel에서도 로컬처럼 수정·등록·삭제 내역이 GitHub 히스토리에 안전하게 영구 저장됩니다.
